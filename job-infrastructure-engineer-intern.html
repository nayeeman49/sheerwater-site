About Sheerwater Consulting

Sheerwater is a UK infrastructure consultancy based in Woking, Surrey. We design and build on-prem, cloud and local AI infrastructure for research groups, startups and small organisations, using Linux, VMware, Proxmox, Ansible and Terraform.

About the programme

This is a structured part-time fully remote 6-month training program, not a job in the usual sense. You will learn the skills UK employers look for in infrastructure engineer roles by building real lab projects, with regular guidance and feedback from a working engineer. It is part-time and remote, and it is voluntary and unpaid. It does not involve client work. You finish with a GitHub portfolio and a clear record of what you built.

What you'll learn

Core skills (we go deep on these)

  • Linux: Rocky Linux and Ubuntu, systemd (systemctl, journalctl), users and permissions, package management (dnf, apt), LVM and storage, SSH, firewalld, SELinux basics, troubleshooting
  • Windows Server and Active Directory: AD, DNS, DHCP, Group Policy, file services and patching
  • PowerShell and Bash: scripting for reports, bulk user creation, health checks and routine admin
  • Virtualisation: Proxmox VE (VMs, templates, backups) and VMware vSphere (ESXi, vCenter, snapshots, resource management)
  • Ansible: inventory, playbooks, roles and automated patching
  • Git and documentation: version control, READMEs, runbooks and diagrams

Introduced to (a taste, not mastery)

  • Networking: TCP/IP, DNS, DHCP, VLANs, VPNs, and tools such as ping, traceroute, ss and tcpdump
  • Terraform and Azure or AWS basics
  • Docker and Kubernetes fundamentals
  • Monitoring with Grafana and Prometheus, and backup and recovery concepts
  • Security basics: MFA, RBAC and patch management

What you'll do

  • Build and secure a Linux server, then patch and repair it
  • Write PowerShell scripts for Windows and Active Directory administration
  • Build a Proxmox lab with templates, clones and tested backups
  • Compare Proxmox and VMware in a short write-up
  • Automate patching and configuration across several servers with Ansible
  • Document every project so someone else can follow it

What you'll get

  • Weekly guided sessions and individual feedback
  • Five finished projects on GitHub
  • An intern title and project descriptions for your CV and LinkedIn
  • A reference from the founder on successful completion, where earned

Who this suits

  • Studying or recently graduated in computing, IT or engineering, or teaching yourself
  • Curious about servers, Linux and automation. No prior experience required.
  • Able to commit around 8 hours a week for 6 months, with breaks for exams
  • A laptop with 16 GB RAM, or willingness to use a shared lab host
