AI service desk cluster

In progress
  • Proxmox
  • Terraform
  • GLPI
  • Local language model

A small on-premises cluster built to test how far an AI agent can safely go inside IT support. The cluster runs on nested Proxmox and is defined in Terraform. GLPI is the service desk, and a language model running locally reads tickets and proposes actions.

The rule that matters: the agent never changes anything on its own. Every action waits for a person to approve it, and every decision is logged. This is the thinking behind our private AI pilot.

Local GPU and ML platform

In progress
  • Kubernetes
  • Prometheus
  • Grafana
  • macOS

A Kubernetes platform for running machine learning workloads on a single desktop machine, with Prometheus and Grafana for monitoring. It is a test bench for the same patterns we use in our Kubernetes baseline: repeatable builds, visible metrics and a runbook.

Current work is on the monitoring network path, so that dashboards show what the cluster is really doing.
