DevOps and Platform Engineer Intern

Learn to build cloud, Kubernetes and automation for real client infrastructure projects.

  • TypeInternship
  • LocationFully remote
  • SalaryNegotiable
Apply for this role

About the role

Work alongside an experienced technical lead and the founder to build the infrastructure that other software runs on. You will start with small, well-defined tasks and take on more as you grow. Everything you build is reviewed before it reaches a client.

What you would work on

  • Write Terraform and Ansible to set up cloud and Linux servers
  • Help build and harden Kubernetes clusters
  • Create CI/CD pipelines that test and deploy software automatically
  • Set up monitoring with tools such as Prometheus and Grafana
  • Document every build in a runbook that clients can follow themselves
  • Take part in weekly demos and explain what you built

Requirements

  • Minimum: a completed bachelor's degree (or final-year student finishing within six months) in computer science, IT, engineering or a related field
  • Good fluency in written and spoken English
  • Working knowledge of Linux on the command line
  • Basic scripting in Bash or Python
  • Understanding of Git and version control
  • Basic knowledge of networking: IP addresses, DNS, firewalls, SSH
  • Careful habits with passwords, keys and changes to live systems
  • Willing to explore new, fun challenges and to learn by building, breaking and fixing things
  • Curious, patient and honest about what you do not yet know

Nice to have

  • A home lab, virtual machines or personal projects you can show us
  • Experience with Docker, Terraform, Ansible, Azure or AWS
  • Progress towards a certification such as Azure Fundamentals, CKA or Terraform Associate

How we assess

A paid task: deploy a small app to Kubernetes from a Git repository, with an automatic pipeline. Every trial task is paid.

How to apply

  1. Send the form

    About five minutes. Include links to your work, such as GitHub, a portfolio or an online CV.

  2. Intro call

    Thirty minutes about your experience and availability.

  3. Paid trial task

    A small, real task with a written brief. You are paid for it.

  4. Offer

    A written agreement covering the work, salary, confidentiality and ownership of what you build.
