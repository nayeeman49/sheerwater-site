Full-Stack Engineer Intern

Build web and mobile products for our own studio products and for client projects.

  • TypeInternship
  • LocationFully remote
  • SalaryFixed
Apply for this role

About the role

Help build the apps, websites and APIs that make up our product and client work. You will pair with experienced engineers, write real features and see them shipped, with code review on everything you submit.

What you would work on

  • Build features across a React or Next.js front end and a Node.js or Python back end
  • Design databases and write clear, tested APIs
  • Build responsive web pages and, where needed, mobile screens
  • Write automated tests alongside your code
  • Review other people's code and learn from reviews of yours
  • Take part in weekly demos and written updates

Requirements

  • Minimum: a completed bachelor's degree (or final-year student finishing within six months) in computer science, software engineering, IT or a related field
  • Good fluency in written and spoken English
  • Solid grounding in JavaScript or TypeScript, plus HTML and CSS
  • Experience building at least one full project with a framework such as React, Node.js, Django or Flask
  • Knowledge of SQL and relational databases
  • Understanding of Git, pull requests and basic testing
  • Willing to explore new, fun challenges and pick up unfamiliar tools quickly
  • Clear written communication and a willingness to ask questions

Nice to have

  • Mobile experience with Flutter or React Native
  • Experience deploying an app to the cloud
  • A public portfolio or GitHub profile with projects you are proud of

How we assess

A paid task: build a small app with login and a simple API in a few days. Every trial task is paid.

How to apply

  1. Send the form

    About five minutes. Include links to your work, such as GitHub, a portfolio or an online CV.

  2. Intro call

    Thirty minutes about your experience and availability.

  3. Paid trial task

    A small, real task with a written brief. You are paid for it.

  4. Offer

    A written agreement covering the work, salary, confidentiality and ownership of what you build.
