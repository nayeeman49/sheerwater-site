About the role

We help organisations use AI on their own data without sending it to third parties. As an intern you will help set up, test and measure open-weight language models and document search tools, with guidance from senior colleagues.

What you would work on

  • Run and test open-weight language models on local and GPU servers
  • Build document search tools that answer questions using a client's own files
  • Prepare and clean data for search and evaluation
  • Measure answer quality and write up what works and what does not
  • Package models and tools in containers so they are easy to deploy
  • Help prototype AI agents where a human approves every action

Requirements

  • Based in Dhaka, Bangladesh. Applications from outside Dhaka cannot be considered.
  • Minimum: a completed bachelor's degree (or final-year student finishing within six months) in computer science, data science, AI, mathematics, engineering or a related field
  • Good fluency in written and spoken English
  • Solid Python, including working with libraries such as NumPy or pandas
  • Understanding of the basics of machine learning and how large language models work
  • Comfortable using Linux and the command line
  • Understanding of Git and version control
  • A habit of testing claims and checking results before reporting them
  • Willing to explore new, fun challenges, including problems nobody has solved before
  • Respect for data privacy and confidentiality

Nice to have

  • Experience with tools such as Ollama, vLLM, LangChain or vector databases
  • Familiarity with Docker and GPUs
  • A thesis, project or portfolio involving machine learning

How we assess

A paid task: run a local model with a simple question-and-answer interface over a handful of PDF files. Every trial task is paid.

How to apply

  1. Send the form

    About five minutes. Include links to your work, such as GitHub, a portfolio or an online CV.

  2. Intro call

    Thirty minutes about your experience and availability.

  3. Paid trial task

    A small, real task with a written brief. You are paid for it.

  4. Offer

    A written agreement covering the work, salary, confidentiality and ownership of what you build.
