QA and Test Automation Engineer Intern

Check our products and client deliveries before anyone else sees them.

  • TypeInternship
  • LocationFully remote
  • SalaryNegotiable
Apply for this role

About the role

Quality is how we earn trust. You will test what the team builds, automate the checks that matter and report problems so clearly that they are easy to fix. It is a strong starting role if you like finding things that others miss.

What you would work on

  • Write and run test cases for web, mobile and API features
  • Automate repeated checks with tools such as Playwright, Selenium or Postman
  • Test infrastructure changes in a staging environment
  • Log defects with clear steps to reproduce them
  • Check fixes and run a release checklist before delivery
  • Keep a simple, current test plan for each project

Requirements

  • Minimum: a completed bachelor's degree (or final-year student finishing within six months) in computer science, IT, engineering or a related field
  • Good fluency in written and spoken English, since clear bug reports matter
  • Basic programming in Python or JavaScript
  • Understanding of how websites and APIs work
  • Strong attention to detail and a patient, methodical approach
  • Understanding of Git
  • Willing to explore new, fun challenges, including breaking things on purpose
  • Honest and constructive when reporting problems

Nice to have

  • Experience with Playwright, Selenium, Cypress or Postman
  • Knowledge of software testing concepts (ISTQB or similar)
  • Basic knowledge of performance or security testing

How we assess

A paid task: test a sample website, report defects clearly and automate three checks. Every trial task is paid.

How to apply

  1. Send the form

    About five minutes. Include links to your work, such as GitHub, a portfolio or an online CV.

  2. Intro call

    Thirty minutes about your experience and availability.

  3. Paid trial task

    A small, real task with a written brief. You are paid for it.

  4. Offer

    A written agreement covering the work, salary, confidentiality and ownership of what you build.
